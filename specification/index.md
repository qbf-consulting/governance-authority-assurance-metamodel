# Normative Specification

{% include gaam-meta.html %}


The [Governance, Authority and Assurance Metamodel v0.9.0](governance-authority-assurance-metamodel.md) is the authoritative human-readable Candidate Specification. It is published from a single Markdown source and rendered through the repository's existing GitHub Pages pipeline.

For standards-oriented review and implementation, use the [Normative Requirement Catalogue](../docs/normative-requirement-catalogue.md) for requirement-level navigation and the [Specification Publication and Reading Guide](../docs/specification-publication.md) for artifact precedence, canonical publication and print/archive guidance.

## Publication model

- Human-readable normative semantics are defined by the specification.
- JSON Schemas are normative for artifact structure.
- Controlled vocabularies govern enumerated semantic values.
- Profiles define composable conformance targets.
- Executable tests provide repository-generated evidence, not independent assessment.
