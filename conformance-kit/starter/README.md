# Foundation Starter Package

This self-contained, illustrative package demonstrates the minimum directory shape accepted by `scripts/gaam.py validate-package`. It contains a Foundation Profile authority artifact, a decision receipt and an L1 conformance claim.

Run from the repository root:

```bash
python scripts/gaam.py validate-package conformance-kit/starter
python scripts/gaam.py validate-claim conformance-kit/starter/artifacts/conformance-claim.json
```

The package is synthetic, self-assessed and informative. It is not an implementation report and does not contribute to candidate-readiness gates.
