# Understand GAAM

Learn the model before working with profiles or machine-readable artifacts.

Start with [Concepts and Design](concepts-and-design.md), then use the [Glossary](glossary.md) for terminology. The conceptual route covers architecture, design principles, lifecycle, diagrams and rationale without replacing the normative specification.

**Core flow:** authority → delegation → decision → effect → evidence → assurance → remedy.
