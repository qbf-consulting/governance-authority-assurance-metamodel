# Concept Classification

Candidate enhancements are assigned to the narrowest delivery layer capable of resolving the observed problem.

| Layer | Use when | Examples |
|---|---|---|
| Informative concept | Existing semantics need sharper explanation | evidence predicates, temporal semantics |
| Draft profile | A bounded conformance target is needed | institutional continuity, advanced agent orchestration |
| Experimental schema | Independent implementations need a common record prototype | qualification, obligation, transition |
| Implementation pattern | A governance mechanism must be exercised end to end | remedy propagation, degraded service operation |
| Behavioural vector | Expected governance outcomes can be tested | scope attenuation, stale revocation state |
| Core normative candidate | The concept is broadly reusable and cannot be represented consistently today | framework composition, authority-scope algebra |

Every register entry records its current coverage, gap classification, proposed layer, dependencies, evidence threshold, and normative impact.
