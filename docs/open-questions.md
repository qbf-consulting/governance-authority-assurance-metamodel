# Candidate Issue Disposition

GAAM Candidate Specification edition v0.9.0 remains the authoritative normative semantic baseline; v0.9.5 is the current Candidate distribution/test-suite release incorporating that frozen edition. The normative baseline contains no unresolved drafting marker that silently changes conformance. Remaining candidate questions are managed as repository issues and MUST be classified as editorial, clarification, compatible extension, breaking normative change or security correction under the candidate stability policy.

The priority review questions are independent implementation feasibility, cross-profile composition, canonical identifier deployment, privacy-preserving receipt design and evidence sufficiency for L2 through L4 claims.
