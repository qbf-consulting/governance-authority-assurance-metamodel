# Support

Use GitHub Issues for reproducible metamodel/schema defects, normative ambiguities, documentation problems, evidence/conformance questions and bounded proposals. Include the affected version/revision, expected and observed interpretation, and the smallest useful evidence reference.

Security-sensitive ambiguity or unsafe authority/delegation behaviour must follow [`SECURITY.md`](SECURITY.md).

GAAM owns its governance/authority/assurance metamodel and normative artifacts; implementations and external standards retain authority over their own runtime and specification decisions.
