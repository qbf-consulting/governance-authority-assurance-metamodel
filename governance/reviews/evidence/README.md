# Candidate Review Evidence

Store evidence under the review domain that produced or relies on it:

- `privacy/`
- `security/`
- `affected-party/`
- `interoperability/`
- `implementation/`
- `future-evolution/`

Evidence files should be stable, attributable and referenced from the relevant review register or finding. Sensitive evidence should not be committed merely to satisfy repository completeness; the register may instead point to a governed external evidence location when disclosure constraints are documented.
