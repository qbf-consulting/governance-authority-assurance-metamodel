# v0.9.1 — Implementation Enablement and Publication Assurance

{% include gaam-meta.html %}

**Release date:** 20 August 2026
**Normative baseline:** v0.9.0

GAAM v0.9.1 is a candidate maintenance release focused on implementation usability, portable testing, release reproducibility and publication evidence. It does not modify GAAM v0.9.0 normative requirements, profile identifiers, canonical schema identifiers, governed vocabulary semantics or conformance levels.

## Material changes

- Separate distribution release identity from the frozen v0.9.0 normative and canonical-schema namespace.
- Add a portable command-line validator for external packages and conformance claims.
- Add an informative adapter protocol and machine-readable result contract for behavioural vectors.
- Add a self-contained Foundation Profile starter package.
- Add delegation-cycle, receipt-integrity, replay and lifecycle replay vectors.
- Make source archives scope-controlled and byte-reproducible using `SOURCE_DATE_EPOCH`.
- Add rendered and remote canonical-schema byte verification, including historical v0.9.0 retention.
- Generate v0.9.1 validation evidence and package checksums while preserving v0.9.0 artifact semantics.

## Compatibility

Existing v0.9.0 conforming artifacts remain valid. Implementations continue to identify `gaamVersion: 0.9.0`, use v0.9.0 profile identifiers and resolve schemas under the v0.9.0 canonical namespace. `0.9.1` identifies the maintenance tooling, distribution and test-suite release.

## Assurance boundary

The starter, reference adapter and repository-generated test results are synthetic or maintainer-produced. They do not satisfy GAAM's independent implementation, independent assessment or cross-implementation interoperability exit criteria for v1.0.0.
